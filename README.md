# audio-waveform-cache

## 题面

时间线放大波形后，峰值总偏移一格、静音轨还出现噪点：桶宽用浮点，边界同时落进两个桶；每桶只记 max，负半周被抹平，波形不对称；RMS 用峰值代替，能量显示偏高；多分辨率层级桶宽不能整除时，末层桶缺失；合并层级对相邻桶取平均，峰值被削；范围查询把末端边界用 `<=` 算进去，多算一个桶；增量更新每次重算全量，复杂度退化到 O(n²)；归一化遇到全静音轨除以 0；批量生成时多条轨道共用同一个桶列表，轨道之间串数据；`bucket=0` 不校验，直接死循环。waveform/peaks.py 是核心，tests/test_peaks.py 15个红。要修的是：桶宽必须为正整数并严格按半开区间分桶；每桶同时保留最小值和最大值；RMS 按平方均值开方；多分辨率每一层都保留不足一桶的尾样本；合并层级保留极值而不是取平均；范围查询使用半开区间 `[start, end)` 排除末端桶；增量更新只改受影响桶；静音轨归一后保持全零；批量生成隔离每条轨道的状态，任一轨非法时整体回滚；桶宽小于 1 时抛出 `WaveformError`。

## 运行方式

在仓库根目录执行：

```bash
python -m pytest tests -q
```

初始失败环境只会使用标准库与 pytest，不需要安装依赖、不访问网络、不使用随机数、不 sleep。期望输出尾部恰好为 `15 failed`，且不能出现 collection、import 或 syntax error。
